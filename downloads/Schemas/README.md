# Schemas

Esta pasta reune os conjuntos publicados na area de downloads:

```text
Schemas/
  SchemasNFSe/
    <municipio>/SchemasNFSe.zip
  SchemasMDFe/
    <arquivos .xsd>
    SchemasMDFe.zip
```

No site, Schemas fica depois de Utilitarios. A pasta principal e as duas subpastas comecam recolhidas e abrem de forma independente, com controles nativos `details/summary`.

Os nomes das pastas municipais e os bytes dos conjuntos NFS-e foram preservados durante a reorganizacao. O Firebird Care continua no mesmo endereco, fora desta pasta.

Consulte [SchemasNFSe/README.md](SchemasNFSe/README.md) e [SchemasMDFe/README.md](SchemasMDFe/README.md) antes de atualizar os pacotes. A listagem e um cadastro fixo: adicionar arquivos nao atualiza automaticamente os botoes do site. Todos os arquivos publicados sao publicos e nao podem ser editados pelos visitantes.

O `.gitattributes` desta pasta impede conversao de quebras de linha nos XSDs, ZIPs e BMPs das duas categorias.
