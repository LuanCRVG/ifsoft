# Imagens do briefing

Esta pasta recebe imagens entregues pela equipe e ilustrações originais aprovadas para as notícias.
Na primeira notícia, `rad-studio-ia-configuracao.png` é a capa e
`delphi-editor-codigo.png` é a imagem do corpo. São cópias integrais dos arquivos
entregues, com legendas que os identificam como ilustrativos, sem autoria confirmada.

Use nomes simples e caminhos relativos. Cadastre arquivo, texto alternativo e legenda
em `briefing-data.js`. Orientações estão em `BRIEFING.md` na raiz do projeto.
Não use a referência do layout como foto da notícia nem atribua autoria sem confirmação.

## Firebird 6

`firebird-6-roadmap.png` é a capa da notícia de 08/10/2026: uma ilustração editorial original gerada com a ferramenta integrada `image_gen`, não com a API ou CLI. O arquivo PNG de 1536 x 1024 pixels foi copiado integralmente da saída gerada, sem recorte ou recompressão.

A imagem não é o logotipo oficial do Firebird, não imita seu emblema e não é uma captura do produto. Sua legenda no site identifica que foi gerada com IA. O texto, as fontes e os prazos da notícia não foram alterados para acrescentar a capa.
