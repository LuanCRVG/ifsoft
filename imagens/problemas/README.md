# Imagens dos problemas

Esta pasta recebe as capturas de tela referenciadas no arquivo `problemas-data.js`.

Use o caminho `imagens/problemas/nome-da-imagem.png` no campo `arquivo` de uma imagem.

Nenhuma imagem foi adicionada nesta etapa. Antes de publicar, oculte dados pessoais, senhas, tokens e outras informacoes confidenciais nas capturas de tela.
